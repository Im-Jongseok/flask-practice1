## 단계 ⑤~⑦: 답 각 두 줄

### ⑤ 배송 기간은 보통 며칠인가?

날짜 오류 147건과 도착일 결측 5건을 제외한 852건의 평균은 **22.05일**, 중앙값은 **2일**이며, 오른쪽 끝 **364~370일의 47건**이 평균을 끌어올립니다.\
0~5일 구간과 크게 떨어진 47건은 별도로 분리하고 날짜는 수정하지 않았습니다. 일반 배송 기간 요약에서만 제외한 **805건**의 평균은 **1.93일**, 중앙값은 **2일**이므로 보통 약 2일입니다.

300일은 두 덩어리를 나누는 분석 기준입니다. 실제 값은 0~5일과 364~370일에만 있어 중간 구간에 관측치가 없습니다. 연도 입력 오류일 가능성만으로 날짜를 1년 줄일 수는 없으므로, 전체 분포와 제외 후 분포를 모두 제시하고 장기 구간 자체를 원본이나 정리 CSV에서 삭제하지 않았습니다.

### ⑥ 만족도가 낮을수록 반품이 많은가?

**아니다.** 만족도 1~5점별 반품 비율은 **7.59%, 11.96%, 7.81%, 8.72%, 6.93%**로 만족도가 낮아질수록 일관되게 높아지지 않습니다.\
2점은 **22/184건(11.96%)**으로 가장 높지만 1점은 **17/224건(7.59%)**이며, 이 비교만으로 낮은 만족도가 반품의 원인이라고 단정할 수 없습니다.

만족도 결측 30건은 이 질문에서만 제외했습니다. 반품 여부를 만족도별로 묶은 평균이며, 분모는 각 만족도의 전체 주문 수입니다.

### ⑦ 카테고리 매출 1위의 차이는 건수·단가·수량 중 어디에 있는가?

**가구가 28.43억 원으로 1위**이며 주문 **213건**·평균 단가 **257,322.91원**으로 두 항목 모두 가장 높습니다. 2위 식품은 **210건·255,232.93원·평균 수량 47.31개**입니다.\
가구의 평균 수량 **51.04개**는 식품보다 많지만 의류 **51.61개**보다 적습니다. 건수·단가가 모두 높고 수량도 높은 편이라는 차이가 있으며, 하나의 요소만이 유일한 원인이라고 단정하지 않습니다.

총매출은 수업과 동일하게 모든 상태의 주문에 기록된 `total_sales`를 합산한 값입니다. 반품 금액 등을 차감한 순매출은 아닙니다.
